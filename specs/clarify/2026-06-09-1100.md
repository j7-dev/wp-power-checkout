# Clarify Session 2026-06-09 11:00

## Idea

規劃實作 payuni-uni-embed-v3 金流功能，需要使用統一的接口 interface。

在 Power Checkout（WooCommerce 結帳整合外掛，DDD 架構，PHP 後端 + Vue 3 / React Blocks 前端）新增一個金流 provider：PAYUNi UNi Embed V3（內嵌式 / 免跳轉支付元件），並強制使用專案既有的統一金流介面 `IPaymentProvider`。

V3 特性：iframe 嵌入式信用卡收單，站內付不跳轉。Flow：後端 `iframe/token_get` 取 SDK_TOKEN → 前端 `uni-payment.js` (JS SDK Ver 2.0) 收集卡片資訊取得綁定結果 → 後端 `iframe/merchant_trade` 完成幕後授權。V3 token_get 階段「不送訂單資料」。加密規則 = AES-256-GCM + SHA256 HashInfo，與既有 `payuni_upp` 完全一致。
