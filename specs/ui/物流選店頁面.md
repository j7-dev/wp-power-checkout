# 綠界全方位物流 v2 RWD 選店頁面

綠界託管的 RWD 響應式物流選擇頁面。顧客觸發選店後，由 WooCommerce 呼叫 RedirectToLogisticsSelection 建立暫存物流單，綠界回傳此 HTML 頁面供導轉。

## 描述

非本系統渲染的頁面（綠界託管）。顧客在此選擇超商門市（或宅配填寫地址）。選店完成後，綠界以瀏覽器 Form POST 將結果（ResultData，含 TempLogisticsID）送回商家的 ClientReplyURL。

## 關鍵屬性

- 由 RedirectToLogisticsSelection（PostWithAesStrResponseService）回傳的 HTML body，非 JSON
- 顯示的物流方式取決於建單參數（超商 FAMI 全家 / UNIMART 統一 / HILIFE 萊爾富、宅配 Home）
- 收件人姓名 / 電話 / 門市等資訊由顧客在此頁填寫，存入綠界暫存物流單（成立正式物流單 CreateByTempTrade 時不需重送）
- 冷凍物流選店：RedirectWithUnimartFreeze（Data 帶 Temperature=0003）
- ServerReplyURL / ClientReplyURL 僅支援 port 80/443，不可放 CDN 後方；本機測試需 ngrok 等 tunnel
- ClientReplyURL 須為公開可訪問 URL（localhost 無效），否則選店後不會 POST 回商家

> 統一抽象對照：此頁面對應 ILogisticsProvider::get_store_selection() 的導轉目標。
> PAYUNi 未來對應 ship_map 門市地圖頁（同為綠界/PAYUNi 託管的導轉選店頁），共用同一抽象階段 A。

## 本系統結帳頁觸發點（WC 整合，C4 定案）

- 綠界物流做成 **WC_Shipping_Method**：顧客在 classic checkout 結帳頁選擇運送方式（超商取貨 FAMI/UNIMART/HILIFE 或宅配 Home）。
- 選擇超商取貨後，結帳頁顯示 **「選擇門市」按鈕**，點按觸發 get_store_selection() → 導轉至本綠界 RWD 選店頁。
- 選店完成回到結帳頁後，按鈕旁顯示已選門市（store_name + store_addr）。
- **classic checkout 先實作；block checkout 選店 UI 第二期後補**（block 整合較複雜）。
